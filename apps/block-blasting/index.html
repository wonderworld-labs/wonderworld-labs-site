Before you begin

A few useful answers.

Does it need an account?

No. Rounds, best scores, badges, and preferences are saved locally.

How many Adventure levels are there?

The current release includes 24 Adventure levels alongside Classic mode.

What happens if I uninstall?

Uninstalling or clearing app storage removes local records. Do not assume a cloud copy will restore them.
