Infinite Craft: How to Test a Recipe Branch

By Wonderworld Labs · Published 2026-11-14

Choose one ingredient and pair it with a small set of other elements. Write down the pairs and results, then choose one discovery as the starting point for the next round.

  • Start with one ingredient
  • Keep a short recipe log
  • Follow one result before changing themes

Start with one ingredient

Use a familiar element as your starting point. For example, make Steam from Water and Fire. Set Steam aside on the board and use it for the next few trials.

Keep a short recipe log

Try your chosen element with two or three ingredients you already have. Write each pair and whatever the game returns. Keep surprising results on the list so you can retrace the branch later.

Follow one result before changing themes

Pick the discovery closest to your current goal and run another small batch with it. If a pair sends you in an unexpected direction, save it as a separate branch and return to your starting element.

Questions and answers

How do I avoid repeating pairs?

Label a short list with your starting element and record each pairing as soon as you try it.
