Asteroid Launcher: How to Read the Simulator Results

By Wonderworld Labs · Published 2026-11-14

After a launch, read the input values first and the result labels second. The energy readout and the map overlays show different outputs of the game model. Keep each result with its unit when comparing runs.

  • Record the settings with the readout
  • Read each overlay separately
  • Compare one change at a time

Record the settings with the readout

Write down the diameter, speed, material and angle from your first run. Choose one result to compare and note the units displayed beside it. This gives you a baseline you can reproduce in the game.

Read each overlay separately

Start with the crater display, then look at the other outputs. Check whether the result describes a diameter, a radius or another distance before comparing the numbers or judging the shapes on the map.

Compare one change at a time

Repeat the run with the same map point and change one setting. Put the two readouts side by side and note which outputs changed. Use the result to describe the simulation and the settings you tested.

Questions and answers

Why are the overlay boundaries different?

The game draws separate overlays for different model outputs. Use each overlay label and its associated result when comparing them.
