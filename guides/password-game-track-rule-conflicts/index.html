The Password Game: How to Track Rule Conflicts

By Wonderworld Labs · Published 2026-11-14

When a new rule appears, identify a part of your in-game string you can edit. Make the smallest change that meets the new rule, then inspect the full rule list before adding anything else.

Give each rule a recognizable chunk

Keep required words and digits easy to spot. Write a note outside the game for any chunk that contributes to several rules. That note gives you a short list of constraints to check after an edit.

Find the effect of required text

A new chunk can add a digit or a letter that affects an earlier rule. If the digit total changes, inspect the digits you just added before editing the old number block. Use the rule feedback to test your explanation.

Check the rule list after every edit

When one edit makes two rules fail, remember the previous string and undo the last change. Try a smaller adjustment to one chunk and check the rule feedback again. Use invented text for the puzzle.

Questions and answers

What should I check when a previously solved rule fails?

Look first at the characters you just added or removed. Check whether the game is counting those characters for the earlier rule too.
