How does Scale Safari work?

Play five rounds of visual size comparisons or numerical estimates. Submit a guess, inspect the reveal, and see your score and recap.

Do I need a calculator?

No. The game is built around your own estimate. Precision entry is available if you want to type a ratio or value directly.

Are the comparisons exact scientific measurements?

The game uses representative values. Size and quantity comparisons are for playful learning; they should not be treated as authoritative measurements.
